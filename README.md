This is normal. When you download any new program, Windows might show a blue or yellow warning saying "Windows protected your PC." That's because the app is new and doesn't have a large reputation yet. To proceed:

### ❓ "unquarantine isn't removing flags from some files"

A few file types are handled differently by Windows (like executables with embedded security certificates). In most cases, unquarantine will still work, but if you find a stubborn file:

- **Manually unlock it:** Right-click the file, choose **"Properties,"** check the **"Unblock"** box at the bottom, click **OK.**

### ❓ "Does it work for files on other drives?"

By default, unquarantine monitors your main Downloads folder. If you keep files on separate drives (like a `D:` drive), add those folders in Settings, and unquarantine will watch them too.
